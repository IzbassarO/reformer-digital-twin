Per-tube population extension of the life model  (v3 results, alloy centralloy_g_4852)
========================================================================================================
Bundle: 7 rows x 48 tubes = 336 tubes; dT ~ Normal(0, sigma), one static
draw per tube, seed 0. Master curve 'Centralloy G 4852' (C = 18.6, lower scatter band).
The offset moves the metal temperature only: firing, feed and pressure are common to the bundle,
so the hoop stress is common to it. t_r,i = t_r(T_wo,max + dT_i, sigma_hoop).

2. VALIDATION OF THE CODE PATH: sampled population mean against the analytic lognormal result
--------------------------------------------------------------------------------------------------------
   E[rate]/rate(T_bar) = exp((a ln10 sigma)^2 / 2) holds exactly only if a were constant in T;
   a = LMP/(scale T^2) falls slowly with T, so a residual is expected on top of the MC error.
