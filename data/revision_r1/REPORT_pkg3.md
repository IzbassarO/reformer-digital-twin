## Отступления от задания (все)

1. **I(b), знак.** «Знак как есть» понят буквально: dT_hot = +w·e_u(load), где e_u = модель − измерение (LOCO). Если считать e_u ошибкой модели, которую надо вычесть, этому соответствует вариант «обратный знак». Оба варианта посчитаны.
2. **I(b), нагрузка.** Нагрузка Plant A и C2 в e_u — это plant rate (0.99 и 0.71), а применяется она к feed_per_tube_fraction модели. Прямая экстраполируется за пределы 0.71–0.99 (0.60–1.10: от +30 до −25 K).
3. **I(b), Table 2.** Сдвиг применён к каждому часу истории по часовой нагрузке. Firing и состояние истории не перерешались — только пересчёт t_r, как требовалось.
4. **J/K, подгонка.** Подгонка — один least_squares из двух стартов (принятое решение и Latham 2011), а не 5 LHS + 1, как в принятой калибровке. При L_q = 0.456 и f_htg = 1.83 воспроизводится принятое решение (χ² 34.94).
5. **J/K, χ²/dof.** dof = 25 (2 свободных параметра), а не 24, как в принятой подгонке с 3 параметрами. Отсюда 1.398 вместо 1.456 при том же χ².
6. **J/K, firing.** Интервал firing 0.75–1.25 шире, чем 0.85–1.15 у surrogate. При f_htg = 0.5 и он недостаточен (9 решений на границе); строка помечена как недействительная.
7. **J/K, S5 y4.** Считается на 6 бинах по времени с физическим подбором firing — так же, как E0-eta в пакете 2. Цель slip — физический slip S1 при данных параметрах.
8. **K(3), d_p для Xu-Froment.** Взят d_p = 9.44 мм из подгонки по перепаду давления (так считаются все XF-прогоны). Определение 6V/S кольца даёт 9.24 мм; оба значения указаны.
9. **K(3), λ_s и излучательная способность.** λ_s = 1.0 W/(m K) и излучательная способность 0.8 в Kunii-Smith — значения по умолчанию в коде (предположение, не данные).
10. **K(3), «середина трубы».** Взят узел, ближайший к L_heated/2: 5.55 м для XF (обогрев 11.12 м), 6.25 м для Plant A. Обратный расчёт XF — значение профиля в ближайшей точке, 5.60 м.
11. **K(3), строки «обратный расчёт» и «калиброванное значение».** Определены каждая только для одного случая; для другого случая стоит «—».
12. **L, сравнение.** N = 512 (первые строки X), а в Table 6 (пакет 1, B) было N = 2048. При p = 0 доли 0.434/0.480 против 0.425/0.484 отражают в основном разницу в N.
13. **M1, T_ref.** На data sheet G 4852 у графика длительной прочности (стр. 6) температурный диапазон не указан, есть только оси LMP 25–32 и σ 1–100 MPa. Как «температура data sheet» взята 1100 °C = 1373 K: это максимальная рабочая температура для steam reforming на стр. 2 и середина высокотемпературных графиков стр. 5 (1000–1200 °C). Второе значение — 1147 K.
14. **M, OAT-прогоны.** Группы взяты из сохранённых OAT-прогонов v3 (seed 1, N = 1024), которые есть только для S1_base, как и в v3.
15. **M2.** Дисперсия t(4) конечна (2·s²), но больше нормальной. Подбор масштаба по 5 %-квантилю, как указано, оставляет хвосты тяжелее, чем в v3.
